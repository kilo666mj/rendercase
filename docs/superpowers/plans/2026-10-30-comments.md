# Artifact Comments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Signed-in viewers can leave anchored, threaded comments on parts of a rendered artifact, and agents can list, reply to, and resolve those threads over MCP.

**Architecture:** Two new PostgreSQL tables hold threads and comments. Shared operations in `internal/app/comments.go` enforce permissions and are called by both the REST handlers (`comments_http.go`) and new MCP tools. The content origin injects a small bridge script into HTML only for tickets minted for signed-in viewers. The bridge talks to a new trusted sidebar (`comments.js`) over `postMessage` and never receives comment text.

**Tech Stack:** Go 1.27 (`go.mod` pins 1.27.1; toolchain auto-download applies), `net/http` ServeMux patterns, pgx v5, PostgreSQL 18, `github.com/modelcontextprotocol/go-sdk` via `go.michaelspost.com/mcpkit`, vanilla browser JavaScript without a build step.

**Spec:** `docs/superpowers/specs/2026-10-30-comments-design.md`

## Global Constraints

- Only signed-in users that `ArtifactForUser` resolves may read or write comments; share sessions, `/shared/*`, and share tickets get no comment routes, UI, or bridge.
- Comment body: 1–10,000 characters (runes) after trimming, plain text, rendered only with `textContent`.
- At most 2,000 comments (including deleted) per artifact; further creates return `409`.
- Comment endpoint request bodies are capped at 64 KiB.
- Anchor: `selector` 1–512 bytes; `quote.exact` 1–500 characters; `quote.prefix` and `quote.suffix` at most 32 characters each; `point.x` and `point.y` in [0, 1]; unknown keys rejected.
- Bridge injection only for `text/html` responses of at most 5 MiB on `artifact:version:c` tickets; tag search scans only the first 64 KiB.
- Audit events for comment mutations contain ids only, never comment bodies.
- Administrators gain no comment access.
- The iframe never receives comment bodies, author names, or thread ids.
- Management templates contain no inline `<script>`, `<style>`, `style=`, or inline event handlers (enforced by `TestManagementTemplatesAvoidInlineScriptAndStyle`).
- Follow `CONTRIBUTING.md`: `go test ./...` and `go vet ./...` must pass; use `example.com` hostnames in tests.

## Review Focus

These are the inputs most likely to break real use that no spec line pins down. Each one has a test in the task that owns the code.

1. **HTML that isn't neatly lowercase ASCII.** Pages with `<HEAD>`, `<header>` before `<head>`, a UTF-8 BOM, or multi-byte characters before the head tag must still get the bridge in the right place without corrupting bytes. The tests are in Task 5.
2. **Comment text with NUL bytes, invalid UTF-8, or multi-byte characters.** `"\u0000"` must return 400, not a 500 from PostgreSQL. 10,000 two-byte characters must be accepted, because the limit counts characters, not bytes. The tests are in Tasks 2 and 3.
3. **Commenters who lose access.** A viewer whose grant is revoked (or whose artifact goes private) must get 404 on their old comments and threads, not 403 or success. The test is in Task 3.
4. **Threads whose every comment was deleted.** These must vanish from listings and refuse replies with 404. The tests are in Tasks 1 and 3.
5. **Version handling across publishes.** Default listing uses the latest version, `version=all` includes earlier versions, threads on a nonexistent version return 404, and a negative or non-numeric version returns 400. The tests are in Task 3.

## Spec corrections discovered while planning

The spec was amended in the same commit as this plan:

- The artifact iframe is sandboxed without `allow-same-origin`, so its origin is opaque (`"null"`). The parent therefore posts to the frame with target `'*'` and accepts frame messages whose `event.origin` is `"null"` (or the content origin) and whose `event.source` is the iframe's `contentWindow`. The bridge learns the management origin from the `enable` message and posts back only to that origin.
- The protocol adds `enabled` (bridge → parent, reply to `enable`; this avoids a `ready`/`enable` loop) and `pick-cancelled` (bridge → parent, Escape pressed inside the frame).
- Nullable fields (`anchor`, `edited_at`, `resolved_at`, `resolved_by`) are omitted when null, so the MCP output schema stays valid.
- REST handlers live in `internal/app/comments_http.go`; shared operations, validation, and views in `internal/app/comments.go`.

- Consumes: `translate`, `rollbackTransaction`, `nullString`, `ErrNotFound` from `postgres.go`.
- Produces (package `store`):
  - `const MaxCommentsPerArtifact = 2000`
  - `var ErrCommentLimit error`
  - `type CommentAuthor struct{ ID, DisplayName string }`
  - `type Comment struct{ ID, ThreadID string; Author CommentAuthor; Body string; CreatedAt time.Time; EditedAt, DeletedAt *time.Time }`
  - `type CommentThread struct{ ID, ArtifactID string; Version int; Anchor json.RawMessage; CreatedBy CommentAuthor; CreatedAt time.Time; ResolvedAt *time.Time; ResolvedBy *CommentAuthor; Comments []Comment }`

  - `type ThreadFilter struct{ Version int; Resolved *bool }` (Version 0 = every version; Resolved nil = both)
  - `(*DB) CreateCommentThread(ctx, NewCommentThread) (CommentThread, error)`: `ErrNotFound` when the artifact or version is missing or deleted; `ErrCommentLimit` at the cap

  - `(*DB) EditComment(ctx, commentID, body string) (Comment, error)`: `ErrNotFound` if deleted
  - `(*DB) DeleteComment(ctx, commentID string) error`: `ErrNotFound` if already deleted
  - `(*DB) SetThreadResolved(ctx, threadID, userID string, resolved bool) (CommentThread, error)`
  - Threads and comments in deleted artifacts are invisible to every read; threads with no live comment are invisible to `CommentThread` and `ListCommentThreads`.

func sameJSON(t *testing.T, got json.RawMessage, want string) {
	t.Helper()
	var g, w any
	if err := json.Unmarshal(got, &g); err != nil {
		t.Fatal(err)
	}
	if err := json.Unmarshal([]byte(want), &w); err != nil {
		t.Fatal(err)
	}
	if !reflect.DeepEqual(g, w) {
		t.Fatalf("JSON = %s, want %s", got, want)
	}
}

CREATE TABLE IF NOT EXISTS comment_threads (
    id text PRIMARY KEY,
    artifact_id text NOT NULL,
    version integer NOT NULL,
    anchor jsonb,
    created_by text NOT NULL REFERENCES users(id),
    created_at timestamptz NOT NULL DEFAULT now(),
    resolved_at timestamptz,
    resolved_by text REFERENCES users(id),
    FOREIGN KEY (artifact_id, version) REFERENCES artifact_versions(artifact_id, version) ON DELETE CASCADE,
    CHECK ((resolved_at IS NULL) = (resolved_by IS NULL))
);
CREATE INDEX IF NOT EXISTS comment_threads_artifact_idx ON comment_threads(artifact_id, version, created_at);

CREATE TABLE IF NOT EXISTS comments (
    id text PRIMARY KEY,
    thread_id text NOT NULL REFERENCES comment_threads(id) ON DELETE CASCADE,
    author_id text NOT NULL REFERENCES users(id),
    body text NOT NULL,
    created_at timestamptz NOT NULL DEFAULT now(),
    edited_at timestamptz,
    deleted_at timestamptz
);
CREATE INDEX IF NOT EXISTS comments_thread_idx ON comments(thread_id, created_at);

- [ ] **Step 4: Implement the store**

Create `internal/store/comments.go`:

```go
package store

import (
	"context"
	"encoding/json"
	"errors"
	"time"

	"github.com/jackc/pgx/v5"
)

const MaxCommentsPerArtifact = 2000

var ErrCommentLimit = errors.New("comment limit reached for this artifact")

type CommentAuthor struct{ ID, DisplayName string }

type Comment struct {
	ID, ThreadID        string
	Author              CommentAuthor
	Body                string
	CreatedAt           time.Time
	EditedAt, DeletedAt *time.Time
}

type CommentThread struct {
	ID, ArtifactID string
	Version        int
	Anchor         json.RawMessage
	CreatedBy      CommentAuthor
	CreatedAt      time.Time
	ResolvedAt     *time.Time
	ResolvedBy     *CommentAuthor
	Comments       []Comment
}

type NewCommentThread struct {
	ThreadID, CommentID, ArtifactID, UserID, Body string
	Version                                       int
	Anchor                                        json.RawMessage
}

// ThreadFilter selects threads. Version 0 selects every version and a nil
// Resolved selects both open and resolved threads.
type ThreadFilter struct {
	Version  int
	Resolved *bool
}

// Threads are visible only while their artifact is active and at least one
// comment in them has not been deleted.
const threadSelect = `SELECT t.id,t.artifact_id,t.version,t.anchor,t.created_by,COALESCE(NULLIF(cu.display_name,''),cu.username),
	t.created_at,t.resolved_at,t.resolved_by,COALESCE(NULLIF(ru.display_name,''),ru.username,'')
	FROM comment_threads t
	JOIN artifacts a ON a.id=t.artifact_id AND a.deleted_at IS NULL
	JOIN users cu ON cu.id=t.created_by
	LEFT JOIN users ru ON ru.id=t.resolved_by
	WHERE EXISTS (SELECT 1 FROM comments live WHERE live.thread_id=t.id AND live.deleted_at IS NULL)`

const commentSelect = `SELECT c.id,c.thread_id,c.author_id,COALESCE(NULLIF(u.display_name,''),u.username),c.body,c.created_at,c.edited_at,c.deleted_at
	FROM comments c JOIN users u ON u.id=c.author_id`

func scanThread(row pgx.Row) (CommentThread, error) {
	var t CommentThread
	var anchor []byte
	var resolvedBy *string
	var resolvedName string
	if err := row.Scan(&t.ID, &t.ArtifactID, &t.Version, &anchor, &t.CreatedBy.ID, &t.CreatedBy.DisplayName, &t.CreatedAt, &t.ResolvedAt, &resolvedBy, &resolvedName); err != nil {
		return CommentThread{}, translate(err)
	}
	if len(anchor) > 0 {
		t.Anchor = json.RawMessage(anchor)
	}
	if resolvedBy != nil {
		t.ResolvedBy = &CommentAuthor{ID: *resolvedBy, DisplayName: resolvedName}
	}
	return t, nil
}

func scanComment(row pgx.Row) (Comment, error) {
	var c Comment
	err := row.Scan(&c.ID, &c.ThreadID, &c.Author.ID, &c.Author.DisplayName, &c.Body, &c.CreatedAt, &c.EditedAt, &c.DeletedAt)
	return c, translate(err)
}

// lockCommentQuota serializes comment creation per artifact and enforces
// MaxCommentsPerArtifact.
func lockCommentQuota(ctx context.Context, tx pgx.Tx, artifactID string) error {
	var id string
	if err := tx.QueryRow(ctx, `SELECT id FROM artifacts WHERE id=$1 AND deleted_at IS NULL FOR UPDATE`, artifactID).Scan(&id); err != nil {
		return translate(err)
	}
	var count int
	if err := tx.QueryRow(ctx, `SELECT count(*) FROM comments c JOIN comment_threads t ON t.id=c.thread_id WHERE t.artifact_id=$1`, artifactID).Scan(&count); err != nil {
		return err
	}
	if count >= MaxCommentsPerArtifact {
		return ErrCommentLimit
	}
	return nil
}

func (d *DB) CreateCommentThread(ctx context.Context, in NewCommentThread) (_ CommentThread, err error) {
	tx, err := d.Pool.Begin(ctx)
	if err != nil {
		return CommentThread{}, err
	}
	defer rollbackTransaction(ctx, tx, &err)
	if err = lockCommentQuota(ctx, tx, in.ArtifactID); err != nil {
		return CommentThread{}, err
	}
	var exists bool
	if err = tx.QueryRow(ctx, `SELECT EXISTS (SELECT 1 FROM artifact_versions WHERE artifact_id=$1 AND version=$2)`, in.ArtifactID, in.Version).Scan(&exists); err != nil {
		return CommentThread{}, err
	}
	if !exists {
		return CommentThread{}, ErrNotFound
	}
	if _, err = tx.Exec(ctx, `INSERT INTO comment_threads(id,artifact_id,version,anchor,created_by) VALUES($1,$2,$3,$4,$5)`,
		in.ThreadID, in.ArtifactID, in.Version, nullString(string(in.Anchor)), in.UserID); err != nil {
		return CommentThread{}, err
	}
	if _, err = tx.Exec(ctx, `INSERT INTO comments(id,thread_id,author_id,body,created_at) VALUES($1,$2,$3,$4,clock_timestamp())`,
		in.CommentID, in.ThreadID, in.UserID, in.Body); err != nil {
		return CommentThread{}, err
	}
	if err = tx.Commit(ctx); err != nil {
		return CommentThread{}, err
	}
	return d.CommentThread(ctx, in.ThreadID)
}

func (d *DB) AddComment(ctx context.Context, commentID, threadID, userID, body string) (_ Comment, err error) {
	tx, err := d.Pool.Begin(ctx)
	if err != nil {
		return Comment{}, err
	}
	defer rollbackTransaction(ctx, tx, &err)
	var artifactID string
	if err = tx.QueryRow(ctx, `SELECT artifact_id FROM comment_threads WHERE id=$1`, threadID).Scan(&artifactID); err != nil {
		return Comment{}, translate(err)
	}
	if err = lockCommentQuota(ctx, tx, artifactID); err != nil {
		return Comment{}, err
	}
	if _, err = tx.Exec(ctx, `INSERT INTO comments(id,thread_id,author_id,body,created_at) VALUES($1,$2,$3,$4,clock_timestamp())`,
		commentID, threadID, userID, body); err != nil {
		return Comment{}, err
	}
	if err = tx.Commit(ctx); err != nil {
		return Comment{}, err
	}
	return d.Comment(ctx, commentID)
}

func (d *DB) CommentThread(ctx context.Context, threadID string) (CommentThread, error) {
	t, err := scanThread(d.Pool.QueryRow(ctx, threadSelect+` AND t.id=$1`, threadID))
	if err != nil {
		return CommentThread{}, err
	}
	threads := []CommentThread{t}
	if err := d.loadComments(ctx, threads); err != nil {
		return CommentThread{}, err
	}
	return threads[0], nil
}

func (d *DB) ListCommentThreads(ctx context.Context, artifactID string, f ThreadFilter) ([]CommentThread, error) {
	rows, err := d.Pool.Query(ctx, threadSelect+` AND t.artifact_id=$1 AND ($2::integer=0 OR t.version=$2)
		AND ($3::boolean IS NULL OR (t.resolved_at IS NOT NULL)=$3) ORDER BY t.created_at,t.id`, artifactID, f.Version, f.Resolved)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	threads := []CommentThread{}
	for rows.Next() {
		t, err := scanThread(rows)
		if err != nil {
			return nil, err
		}
		threads = append(threads, t)
	}
	if err := rows.Err(); err != nil {
		return nil, err
	}
	return threads, d.loadComments(ctx, threads)
}

func (d *DB) loadComments(ctx context.Context, threads []CommentThread) error {
	if len(threads) == 0 {
		return nil
	}
	ids := make([]string, len(threads))
	index := make(map[string]int, len(threads))
	for i, t := range threads {
		ids[i] = t.ID
		index[t.ID] = i
		threads[i].Comments = []Comment{}
	}
	rows, err := d.Pool.Query(ctx, commentSelect+` WHERE c.thread_id=ANY($1) ORDER BY c.created_at,c.id`, ids)
	if err != nil {
		return err
	}
	defer rows.Close()
	for rows.Next() {
		c, err := scanComment(rows)
		if err != nil {
			return err
		}
		i := index[c.ThreadID]
		threads[i].Comments = append(threads[i].Comments, c)
	}
	return rows.Err()
}

func (d *DB) Comment(ctx context.Context, commentID string) (Comment, error) {
	return scanComment(d.Pool.QueryRow(ctx, commentSelect+`
		JOIN comment_threads t ON t.id=c.thread_id
		JOIN artifacts a ON a.id=t.artifact_id AND a.deleted_at IS NULL
		WHERE c.id=$1`, commentID))
}

func (d *DB) EditComment(ctx context.Context, commentID, body string) (Comment, error) {
	ct, err := d.Pool.Exec(ctx, `UPDATE comments SET body=$2,edited_at=now() WHERE id=$1 AND deleted_at IS NULL`, commentID, body)
	if err != nil {
		return Comment{}, err
	}
	if ct.RowsAffected() != 1 {
		return Comment{}, ErrNotFound
	}
	return d.Comment(ctx, commentID)
}

func (d *DB) DeleteComment(ctx context.Context, commentID string) error {
	ct, err := d.Pool.Exec(ctx, `UPDATE comments SET body='',deleted_at=now() WHERE id=$1 AND deleted_at IS NULL`, commentID)
	if err != nil {
		return err
	}
	if ct.RowsAffected() != 1 {
		return ErrNotFound
	}
	return nil
}

func (d *DB) SetThreadResolved(ctx context.Context, threadID, userID string, resolved bool) (CommentThread, error) {
	var err error
	if resolved {
		_, err = d.Pool.Exec(ctx, `UPDATE comment_threads SET resolved_at=COALESCE(resolved_at,now()),resolved_by=COALESCE(resolved_by,$2) WHERE id=$1`, threadID, userID)

package app

import (
	"bytes"
	"encoding/json"
	"fmt"
	"strings"
	"time"
	"unicode/utf8"

	"github.com/kilo666mj/rendercase/internal/store"
)

const (
	maxCommentRunes        = 10000
	maxCommentRequestBytes = 64 << 10
	maxAnchorSelectorBytes = 512
	maxAnchorQuoteRunes    = 500
	maxAnchorContextRunes  = 32
)

// commentInputError marks client mistakes; its message is safe to return.
type commentInputError struct{ msg string }

func (e commentInputError) Error() string { return e.msg }

func normalizeCommentBody(v string) (string, error) {
	if !utf8.ValidString(v) || strings.ContainsRune(v, 0) {
		return "", commentInputError{"comment must be valid UTF-8 text without NUL characters"}
	}
	v = strings.TrimSpace(v)
	n := utf8.RuneCountInString(v)
	if n == 0 {
		return "", commentInputError{"comment must not be empty"}
	}
	if n > maxCommentRunes {
		return "", commentInputError{fmt.Sprintf("comment exceeds %d characters", maxCommentRunes)}
	}
	return v, nil
}

type commentAnchor struct {
	Selector string       `json:"selector"`
	Quote    *anchorQuote `json:"quote,omitempty"`
	Point    *anchorPoint `json:"point,omitempty"`
}

type anchorQuote struct {
	Exact  string `json:"exact"`
	Prefix string `json:"prefix,omitempty"`
	Suffix string `json:"suffix,omitempty"`
}

type anchorPoint struct {
	X float64 `json:"x"`
	Y float64 `json:"y"`
}

func hasControl(v string) bool {
	return strings.ContainsFunc(v, func(r rune) bool { return r < 0x20 || r == 0x7f })
}

// validateAnchor checks an untrusted anchor from the browser and returns its
// normalized encoding, or nil for a comment on the whole version.
func validateAnchor(raw json.RawMessage) (json.RawMessage, error) {
	trimmed := bytes.TrimSpace(raw)
	if len(trimmed) == 0 || bytes.Equal(trimmed, []byte("null")) {
		return nil, nil
	}
	dec := json.NewDecoder(bytes.NewReader(trimmed))
	dec.DisallowUnknownFields()
	var a commentAnchor
	if err := dec.Decode(&a); err != nil || dec.More() {
		return nil, commentInputError{"anchor must be an object with selector, quote, and point"}
	}
	if a.Selector == "" || len(a.Selector) > maxAnchorSelectorBytes || !utf8.ValidString(a.Selector) || hasControl(a.Selector) {
		return nil, commentInputError{fmt.Sprintf("anchor selector must be 1 to %d bytes of printable text", maxAnchorSelectorBytes)}
	}
	if q := a.Quote; q != nil {
		if q.Exact == "" || utf8.RuneCountInString(q.Exact) > maxAnchorQuoteRunes {
			return nil, commentInputError{fmt.Sprintf("anchor quote must be 1 to %d characters", maxAnchorQuoteRunes)}
		}
		if utf8.RuneCountInString(q.Prefix) > maxAnchorContextRunes || utf8.RuneCountInString(q.Suffix) > maxAnchorContextRunes {
			return nil, commentInputError{fmt.Sprintf("anchor quote context must be at most %d characters", maxAnchorContextRunes)}
		}
		if strings.ContainsRune(q.Exact+q.Prefix+q.Suffix, 0) {
			return nil, commentInputError{"anchor quote must not contain NUL characters"}
		}
	}
	if p := a.Point; p != nil && (p.X < 0 || p.X > 1 || p.Y < 0 || p.Y > 1) {
		return nil, commentInputError{"anchor point coordinates must be between 0 and 1"}
	}
	return json.Marshal(a)
}

type commentAuthorView struct {
	ID          string `json:"id"`
	DisplayName string `json:"display_name"`
}

type commentView struct {
	ID        string            `json:"id"`
	Author    commentAuthorView `json:"author"`
	Body      string            `json:"body"`
	CreatedAt time.Time         `json:"created_at"`
	EditedAt  *time.Time        `json:"edited_at,omitempty"`
	Deleted   bool              `json:"deleted"`
	CanEdit   bool              `json:"can_edit"`
	CanDelete bool              `json:"can_delete"`
}

type threadView struct {
	ID         string             `json:"id"`
	Version    int                `json:"version"`
	Anchor     *commentAnchor     `json:"anchor,omitempty"`
	CreatedBy  commentAuthorView  `json:"created_by"`
	CreatedAt  time.Time          `json:"created_at"`
	ResolvedAt *time.Time         `json:"resolved_at,omitempty"`
	ResolvedBy *commentAuthorView `json:"resolved_by,omitempty"`
	CanResolve bool               `json:"can_resolve"`
	Comments   []commentView      `json:"comments"`
}

func canModerateComments(a store.Artifact) bool { return a.Role == "owner" || a.Role == "editor" }

func authorView(a store.CommentAuthor) commentAuthorView {
	return commentAuthorView{ID: a.ID, DisplayName: a.DisplayName}
}

func newCommentView(c store.Comment, a store.Artifact, u store.User) commentView {
	deleted := c.DeletedAt != nil
	own := c.Author.ID == u.ID
	return commentView{
		ID: c.ID, Author: authorView(c.Author), Body: c.Body, CreatedAt: c.CreatedAt, EditedAt: c.EditedAt,
		Deleted: deleted, CanEdit: !deleted && own, CanDelete: !deleted && (own || canModerateComments(a)),
	}
}

func newThreadView(t store.CommentThread, a store.Artifact, u store.User) threadView {
	v := threadView{
		ID: t.ID, Version: t.Version, CreatedBy: authorView(t.CreatedBy), CreatedAt: t.CreatedAt, ResolvedAt: t.ResolvedAt,
		CanResolve: t.CreatedBy.ID == u.ID || canModerateComments(a), Comments: make([]commentView, 0, len(t.Comments)),
	}
	if len(t.Anchor) > 0 {
		var anchor commentAnchor
		// Stored anchors were validated on write; a decode failure only hides the pin.
		if json.Unmarshal(t.Anchor, &anchor) == nil {
			v.Anchor = &anchor
		}
	}
	if t.ResolvedBy != nil {
		by := authorView(*t.ResolvedBy)
		v.ResolvedBy = &by
	}
	for _, c := range t.Comments {
		v.Comments = append(v.Comments, newCommentView(c, a, u))
	}
	return v
}

func decodeJSONLimit(w http.ResponseWriter, r *http.Request, v any, limit int64) bool {
	r.Body = http.MaxBytesReader(w, r.Body, limit)

func parseThreadQuery(v url.Values) (threadQuery, error) {
	open := false
	q := threadQuery{Resolved: &open}
	switch raw := v.Get("version"); raw {
	case "":
	case "all":
		q.AllVersions = true
	default:
		n, err := strconv.Atoi(raw)
		if err != nil || n < 1 {
			return threadQuery{}, commentInputError{"version must be a positive integer or all"}
		}
		q.Version = n
	}
	switch v.Get("resolved") {
	case "", "false":
	case "true":
		resolved := true
		q.Resolved = &resolved
	case "all":
		q.Resolved = nil
	default:
		return threadQuery{}, commentInputError{"resolved must be true, false, or all"}
	}
	return q, nil
}

func (s *Server) writeCommentError(w http.ResponseWriter, r *http.Request, err error) {
	var input commentInputError
	switch {
	case errors.As(err, &input):
		writeError(w, http.StatusBadRequest, input.Error())
	case errors.Is(err, errCommentArtifactNotFound), errors.Is(err, errCommentVersionNotFound),
		errors.Is(err, errCommentThreadNotFound), errors.Is(err, errCommentNotFound):
		writeError(w, http.StatusNotFound, err.Error())

		writeError(w, http.StatusForbidden, err.Error())
	case errors.Is(err, store.ErrCommentLimit):
		writeError(w, http.StatusConflict, err.Error())
	default:
		s.fail(w, r, err)
	}
}

import (
	"bytes"
	"strconv"

const (
	bridgeScriptPath     = "/_rc/bridge.js"
	commentTicketSuffix  = ":c"
	maxBridgeInjectBytes = 5 << 20
	bridgeScanBytes      = 64 << 10
)

var (
	bridgeTag = []byte(`<script src="` + bridgeScriptPath + `"></script>`)
	utf8BOM   = []byte{0xEF, 0xBB, 0xBF}
)

// contentTicketSubject names what a viewer ticket authorizes. Tickets minted
// for signed-in viewers carry the comment suffix so their HTML gets the bridge;
// share-link tickets never do.
func contentTicketSubject(artifactID string, version int, comments bool) string {
	subject := artifactID + ":" + strconv.Itoa(version)
	if comments {
		subject += commentTicketSuffix
	}
	return subject
}

func ticketAllows(subject, artifactID string, version int) (ok, comments bool) {
	base := contentTicketSubject(artifactID, version, false)
	switch subject {
	case base:
		return true, false
	case base + commentTicketSuffix:
		return true, true
	}
	return false, false
}

// injectBridge inserts the bridge script after the first <head>, <html>, or
// doctype tag found in the first bridgeScanBytes, or at the start of the
// document. Matching is ASCII case-insensitive so byte offsets stay valid.
func injectBridge(doc []byte) []byte {
	lower := asciiLower(doc[:min(len(doc), bridgeScanBytes)])
	at := openingTagEnd(lower, "<head")
	if at < 0 {
		at = openingTagEnd(lower, "<html")
	}
	if at < 0 {
		at = openingTagEnd(lower, "<!doctype")
	}
	if at < 0 {
		at = 0
		if bytes.HasPrefix(doc, utf8BOM) {
			at = len(utf8BOM)
		}
	}
	out := make([]byte, 0, len(doc)+len(bridgeTag))
	out = append(out, doc[:at]...)
	out = append(out, bridgeTag...)
	return append(out, doc[at:]...)
}

func asciiLower(b []byte) []byte {
	out := make([]byte, len(b))
	for i, c := range b {
		if 'A' <= c && c <= 'Z' {
			c += 'a' - 'A'
		}
		out[i] = c
	}
	return out
}

// openingTagEnd returns the index just past the '>' closing the first tag
// that starts with prefix and is followed by a tag-name terminator, or -1.
func openingTagEnd(lower []byte, prefix string) int {
	for from := 0; ; {
		i := bytes.Index(lower[from:], []byte(prefix))
		if i < 0 {
			return -1
		}
		next := from + i + len(prefix)
		if next < len(lower) && isTagNameEnd(lower[next]) {
			if end := bytes.IndexByte(lower[next:], '>'); end >= 0 {
				return next + end + 1
			}
			return -1
		}
		from = next
	}
}

func isTagNameEnd(c byte) bool {
	switch c {
	case ' ', '\t', '\n', '\r', '\f', '/', '>':
		return true
	}
	return false
}

## Comments

Signed-in viewers can comment on an artifact from its viewer page. **Add
comment** lets a reviewer click an element or select text inside the artifact;
**Comment on whole version** leaves a comment that is not tied to one element.
Replies form threads, and the thread author, the owner, and editors can resolve
or reopen them. Comments are plain text, at most 10,000 characters, and each
artifact holds at most 2,000.

Comments are never shown through capability share links. Anchoring works
through a small script that the content origin adds to HTML files of 5 MiB or
less, and only for signed-in views; share-link responses stay byte-identical to
the uploaded bundle. The script receives only pin positions, never comment text
or author names.

Agents read feedback with `rendercase_list_comments`, reply with
`rendercase_reply_comment`, and close the loop with
`rendercase_resolve_comment_thread` after publishing a fixed version. The REST
API is under `/api/v1/artifacts/{artifact}/threads`, `/api/v1/threads/{thread}`,
and `/api/v1/comments/{comment}`.
```
